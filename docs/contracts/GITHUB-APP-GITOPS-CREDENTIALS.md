# Retired credential contract

**Status:** Superseded and non-authoritative.

The hosted delivery profile uses the built-in workflow token for the minimum
native workflow results required by the checks. Pull-request creation,
promotion approval, protection changes, cleanup, and release publication are
separate operator actions and must use the authenticated procedure recorded by
Terra; this file does not define credentials or permit their creation.

Historical credential evidence is retained in the archive and may be read only
to explain provenance. Do not use this file as an implementation or operations
source.
