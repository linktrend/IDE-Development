# LiNKdeveloper Stage 1 — Declaration

**Status:** Complete — verified for use  
**Date:** 2026-07-10

## What Stage 1 is

**LiNKdeveloper** is this repository (`IDE Development` on disk, `linktrend/IDE-Development` on GitHub). **Stage 1** is the semi-manual **Application Factory** operating system — doctrine, artifacts, workflows, contracts, and hybrid skills for building venture applications:

```
Intent → Program → Module → Phase → Issue → Proof → Review → Integration → Complete
```

Stage 1 is **not** the operations workflow for Website, Automation, or Content factories. That skeleton lives in [`docs/FACTORY-OPERATIONS-BLUEPRINT.md`](FACTORY-OPERATIONS-BLUEPRINT.md) (planning only until factory ops work starts).
