# Session Handoffs

Session handoff reports capture completed work, remaining tasks, blockers, and recommended next actions so the next session can resume safely.

## Template

Copy [`_TEMPLATE.md`](_TEMPLATE.md) to a dated file when ending a session:

```text
docs/handoff/YYYY-MM-DD.md
```

Use the session date in the filename. One handoff per close-out is enough; overwrite the same date only when correcting the same session.

## When to write

Session lifecycle docs under `core/session/` and `core/bootstrap/` define when handoffs are required. Typical triggers:

- natural-language session end
- cross-IDE or cross-machine handoff
- stopping work with unfinished issues or pending gates
