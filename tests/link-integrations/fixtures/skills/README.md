# LiNKskills consumer fixtures (WP-I6-S4)

Local synthetic release objects and the bounded completed-use subset of
pin-time `use-report-v0.2` (`report_kind`, `score`, `skill_release_ref`,
`actor_ref`, optional `issue.issue_ref`). Provider commit/tree match the S0
LiNKskills pin. Digests and opaque refs are fixture labels, not live payloads.
Any exact `latest` segment separated by `/`, `:`, or `@` is fail-closed.
Missing/null/empty pin material is unavailable; present wrong-type or non-SHA
pins and malformed compatibility values are fail-closed. Do not execute a
skill, call Skills HTTP, edit LiNKskills, add credentials or network adapters,
or install nested `.ide-development/`.
