# Plan Module

Use when a program or approved scope needs to be decomposed into phases and executable issues.

Operational summary:

- start from `MODULE.md` (application: one of the six fixed Module IDs)
- define product-specific `PHASE.md` and `ISSUE.md` artifacts inside that Module
- do not create additional top-level application Modules
- make dependencies explicit
- stop once at least one issue can be identified as `ready` or explicitly `blocked`

Read and execute `.cursor/prompts/execution/PLAN-MODULE.md`.
